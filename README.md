## Overview

### The challenge

The goals for this challenge are to:

- Show a layout suited to different screen sizes.
- Provide visible hover and keyboard-focus states for interactive elements.
- Let users open and close the navigation menu at any screen size.

The menu also closes when the user presses Escape.

### What I learned

This project was a chance to practice using CSS Grid for the main page layout, then changing the grid at a mobile breakpoint so the content stacks in a single column.

I also practiced connecting a button to a navigation panel with JavaScript. The button's `aria-expanded` value reflects whether the panel is open, which helps assistive technologies communicate the menu's state.
